Live 横滑预览

展示位置

  • 横滑 Live 预览位于 All + Today 的日期栏下方、热门联赛目录上方；View all 进入独立 Live 页面。

展示内容

  • 显示 Live now / 场次数 / View all 标题行和横滑卡；卡片包含赛徽、比赛分钟、双方队徽、队名和比分。
  • 横滑两端分别提供 Finished 与 Upcoming 入口；首屏完整展示 1 张卡并露出下一张。

交互

  • 横滑卡点击后进入比赛内页；View all 进入独立 Live 页面，Finished / Upcoming 入口进入对应状态列表。
  • 从独立 Live 页面返回时恢复 All、原日期和滚动位置。

边界处理

  • 0 场进行中：保留 Live now 0 和 View all 入口，不显示横滑比赛卡。
  • 仅 1 场进行中：显示 Live now 1 和单张加宽比赛卡，保留 View all；不复制卡片填满横滑区域。
  • 最后一场刚结束：该卡片移出横滑预览，场次数更新为 0；Live now 和 View all 入口继续保留。
  • 比赛状态加载中：保留模块原有高度并显示卡片骨架；加载失败时隐藏该模块，All 的其他比赛入口仍可使用。
  • 比分或队徽暂缺：比分显示短横线、队徽显示固定尺寸占位，卡片高度和左右滑动位置不变化。

页面说明

B 测试差异

  • 新增独立 Recommended 页签；B 顶部只保留 All / Recommended。

比赛列表

展示内容

  • Recommended 列表显示符合以下任一条件的比赛：至少一支参赛球队为用户关注球队；或至少一支参赛球队在 Eleven 后台“热门球队优先级”中归属前三优先级。
  • 同一场比赛同时满足两个条件时，列表内只展示一次；不显示推荐原因或额外解释标签。
  • 比赛字段与视觉样式复用线上比赛行，列表按开赛时间展示。

交互

  • 上下滑动列表跨入新的日期分组时，顶部日期同步选中当前浏览日期；点击顶部日期时，列表滚动到对应日期分组。
  • 点击任一比赛行直接进入比赛内页。
  • 点击联赛标识或联赛名称进入联赛资料页；点击右侧箭头仅展开或收起该联赛比赛，不进入联赛资料页。

边界处理

  • 无精选比赛时显示线上空态；缺少开赛时间的比赛排在列表末尾。

比赛列表优化 A/B 测试

对照组 / A / B 三组测试

方案 B · 横滑直播预览打开方案 A Live
正在载入原型

测试方法

  • 新用户与老用户分别按 1:1:1 随机分组：对照组（线上现状）、A 组（独立 Live 页签）、B 组（All 内横滑 Live 预览）。
  • 仅在当前最新 App 版本进行测试；仍使用旧版本的用户不参与实验。

需要验证的数据

  • Recommended 页面日 UV = 当天至少进入 1 次 Recommended 页面的去重用户数。
  • Recommended 页面日 PV = 当天进入 Recommended 页面的总次数；同一用户同日重复进入继续累计。
  • Recommended 页面使用渗透率 = Recommended 页面日 UV ÷ Match 模块日 UV。
  • Recommended 页面人均日访问次数 = Recommended 页面日 PV ÷ Recommended 页面日 UV；同日复访率 = 当天进入 Recommended 页面至少 2 次的去重用户数 ÷ Recommended 页面日 UV。
  • Match 模块日 UV = 当天至少进入 1 次 Match 模块的去重用户数。
  • Match 模块日 PV = 当天进入 Match 模块的总次数；同一用户离开后再次进入继续累计，模块内切换 All / Recommended / Live 不重复计算。
  • Match 模块人均日访问次数 = Match 模块日 PV ÷ Match 模块日 UV；同日复访率 = 当天进入 Match 模块至少 2 次的去重用户数 ÷ Match 模块日 UV。
  • Match 比赛详情转化率 = 当天从 Match 模块打开任一比赛详情的去重用户数 ÷ Match 模块日 UV。
  • D1 / D7 Match 留存率 = 首次进入实验后第 1 / 7 天再次进入 Match 模块的去重用户数 ÷ 对应首次进入实验的去重用户数。
