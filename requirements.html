All 页面

方案 B · All页面调整 + Live 横滑预览

页面调整

展示内容

  • 原 Explore 更名为 All；All 仅移除 You may like，热门联赛和 All Competitions 保持原样。
  • 顶部使用 All / Recommended 两个页签；All 保持默认入口。

展示内容

  • 原 Explore 更名为 All；All 仅移除 You may like，热门联赛和 All Competitions 保持原样。
  • 顶部使用 All / Recommended / Live 三个页签；All 内不增加横滑 Live 预览。

保持不变

  • 状态栏、日期栏和底部导航沿用原版；切换页签时高度、字号和间距不变。

Live 横滑预览

展示位置

  • 横滑 Live 预览位于 All + Today 的日期栏下方、热门联赛目录上方；View all 进入独立 Live 页面。

展示内容

  • 显示 Live now / 场次数 / View all 标题行和横滑卡；卡片包含赛徽、比赛分钟、双方队徽、队名和比分。
  • 横滑两端分别提供 Finished 与 Upcoming 入口；首屏完整展示 1 张卡并露出下一张。

交互

  • 横滑卡点击后进入比赛内页；View all 进入独立 Live 页面，Finished / Upcoming 入口进入对应状态列表。
  • 从独立 Live 页面返回时恢复 All、原日期和滚动位置。

边界处理

  • 0 场进行中：隐藏 Live now 标题行和整组横滑卡，热门联赛目录直接上移，不保留空白占位。
  • 仅 1 场进行中：显示 Live now 1 和单张加宽比赛卡，保留 View all；不复制卡片填满横滑区域。
  • 最后一场刚结束：当前卡片先更新为 FT；用户再次进入 All 时移除整组 Live 入口，避免浏览过程中内容突然跳动。
  • 比赛状态加载中：保留模块原有高度并显示卡片骨架；加载失败时隐藏该模块，All 的其他比赛入口仍可使用。
  • 比分或队徽暂缺：比分显示短横线、队徽显示固定尺寸占位，卡片高度和左右滑动位置不变化。

Recommended 页面

方案 B · Recommended用户关注球队 + Eleven 热门球队前三优先级

页面入口与日期

B 测试差异

  • 新增独立 Recommended 页签；B 顶部只保留 All / Recommended。

展示位置

  • Recommended 作为 All 右侧的同级页签；列表位于公共日期栏下方。
  • 从其他页签进入时保留用户当前选择的日期；没有历史选择时默认 Today。进入日期分组后，优先定位第一场进行中的比赛；没有进行中比赛时定位最近开赛的未开始比赛；当天比赛全部结束时定位最近结束的一场。

展示位置

  • Recommended 位于 All 与 Live 之间；列表位于公共日期栏下方。
  • 从其他页签进入时保留用户当前选择的日期；没有历史选择时默认 Today。进入日期分组后，优先定位第一场进行中的比赛；没有进行中比赛时定位最近开赛的未开始比赛；当天比赛全部结束时定位最近结束的一场。

交互

  • 上下滑动列表跨入新的日期分组时，顶部日期同步选中当前浏览日期；点击顶部日期时，列表滚动到对应日期分组。

比赛列表

展示内容

  • Recommended 展示两类比赛：至少一支参赛球队为用户关注球队；或至少一支参赛球队在 Eleven 后台“热门球队优先级”中归属前三优先级。同时命中两类条件时只展示一次，不显示推荐原因或额外解释标签。
  • 比赛字段与视觉样式复用线上比赛行，列表按开赛时间展示。

交互

  • 点击任一比赛行直接进入比赛内页；点击星标不触发跳转。

边界处理

  • 用户未关注任何球队时，仅展示至少一支参赛球队在 Eleven 后台“热门球队优先级”中归属前三优先级的比赛。
  • 当前日期没有符合条件的比赛时显示线上空态，不自动跳到其他日期；缺少开赛时间的比赛排在列表末尾。

比赛列表优化 A/B 测试

对照组 / A / B 三组测试

方案 B · 横滑直播预览打开方案 A Live

测试方法

  • 符合条件的用户按 1:1:1 随机分为：对照组（线上现状）、A 组（独立 Live 页签）、B 组（All 内横滑 Live 预览）。
  • 仅纳入进入 Match + Today 且当日至少有 1 场直播的用户；按 user_id 固定分组，未登录用户按稳定 device_id 分组。实验运行至少 14 天并覆盖两个完整周末。
  • A、B 分别与对照组比较；若两组均显著提升，再比较 A 与 B。

需要验证的数据

  • Live 入口曝光用户数 = 看到 A 组 Live 页签或 B 组横滑 Live 入口的去重用户数。
  • Live 内容进入率 = 点击 Live 页签，或点击 View all / Finished / Upcoming 进入 Live 内容的去重用户数 ÷ Live 入口曝光去重用户数。
  • Live 来源比赛详情转化率 = 从横滑卡或 Live 列表打开比赛详情的去重用户数 ÷ Live 入口曝光去重用户数。
  • Match 比赛详情转化率 = 从 Match 页面打开任一比赛详情的去重用户数 ÷ Match 页面曝光去重用户数。
  • 首次打开比赛详情耗时 P50 = 同一会话内首次打开比赛详情时间 - Match 页面首次曝光时间，并取全部有效会话的中位数。
  • 单次会话比赛详情打开数 = 从 Match 页面打开比赛详情的总次数 ÷ Match 页面会话数。
  • D1 / D7 Match 留存率 = 首次进入实验后第 1 / 7 天再次进入 Match 页面的去重用户数 ÷ 对应首次进入实验的去重用户数。
  • 以上指标均按 variant 区分对照组、A 组和 B 组，并携带用户或设备 ID、入口来源、selected_date、live_count、match_id 和比赛状态。
